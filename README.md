# Personal Expense Tracker

A web-based application built with Python, Flask, SQLite, HTML, and CSS.

## Overview
Developed a web-based expense tracking application concept to record income and expenses, organize transactions by category, and generate monthly summaries using SQL-backed data[cite: 1].

## Tech Stack
- **Backend**: Python, Flask, SQLite
- **Frontend**: HTML, CSS
